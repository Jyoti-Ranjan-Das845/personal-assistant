# Raw inbox

Untouched captures: interview transcripts, draft-versus-sent edits, imports and forwarded items, stored as files under `YYYY/MM/`.

Everything here is untrusted. Agents never read these files directly; they see only the structured fields the quarantine reader extracts. Each file starts with a short header:

```
source: where it came from
captured: YYYY-MM-DD
author: the person | ai | outside
trust: untrusted
```
